Quark's revised Chinese spellings differ from existing localization on 15 moves, two abilities and one item. Existing labels are retained and upstream spellings added as aliases; these differences are logged rather than silently declaring one independently official. Bare names still do not select a form. Stats and learnsets are available in the snapshot; no damage or strategic features were added.

## Redistribution

Quark's LICENSE permits redistribution of original software under MIT with its notice retained; `LICENSE.quark.txt` and `NOTICE.quark.txt` are bundled. Its NOTICE explicitly describes community-derived battle facts. This is not a blanket license grant for every upstream site's text, translation or asset. This repository includes only transformed factual catalog fields and name aliases, no effect descriptions, sprites, source scrape caches, rankings or calculator code. Third-party redistribution rights for the full upstream datasets are **not established**; do not represent this snapshot as universally MIT-cleared. Confirm upstream permissions before redistributing richer content.

PokeDD README says MIT, but the inspected tree has no LICENSE file. Its files are inspected for comparison and not copied into the shipped dataset. Old CC-BY-4.0 source attribution/license, PokeAPI BSD-3-Clause and Unicode-3.0 notices are retained with the archive and current localization artifacts. Pokémon trademarks are not licensed by these repository licenses.

## Refresh procedure

1. Fetch both repositories into external checkouts, select revisions dated no later than the intended as-of date, and record `git log -1` plus path-specific logs. Review the data's internal timestamps, README attribution, LICENSE/NOTICE and release metadata separately. Do not equate HEAD/release/metagame dates with fact dates.
2. Download the eligible-roster HTML from the exact URL linked by the current official regulation announcement using HTTPS certificate validation. Save acquisition date and SHA-256. Review the embedded `const pokemons` array and regulation duration; a new regulation requires reviewing the importer rule and explicit Mega announcements.
3. Run:
   ```sh
   .venv/bin/python scripts/refresh_champions.py --quark /path/to/quark --pokedd /path/to/pokedd --official-html /path/to/official.html --as-of 2026-10-13
   ```
   The build reads pinned checkouts offline, starts from the archived canonical dictionary, writes local checksums and never updates the archived April files. Review `coverage.json` and `manifest.json` before accepting a refreshed snapshot. This importer currently targets M-C; change its explicit identifiers/rules for future regulations, rather than relabeling an old list.
4. Inspect changes in stats, move fields, learnsets and aliases, resolve ambiguous forms with independent evidence, and review third-party licenses. Run `.venv/bin/pytest -q`, rerun real fixture recognition, and record the resulting snapshot ID with screenshot evidence. No refresh happens at recognition runtime.

Use `KnowledgeBase(Path('knowledge/archive/2026-04-16-v1.1.0'))` for historical recognition; default `KnowledgeBase()` loads current M-C. Explicit unknown game-version requests never borrow another build's availability.
