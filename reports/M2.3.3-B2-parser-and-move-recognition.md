## Supported constructions and evidence semantics

`battle_events/parser.py` adds focused, whole-message constructions:

- `<actor>拍落了[对手的]<owner>的<exact item>！`: `item_change/remove`. The state-event actor is the item owner; the attacking species remains `removal_actor`. No damage or item consumption follows from this text.
- `<actor>用白色香草复原了能力！`: `item_activation`, with `reported_effect=stat_restoration`, unknown affected stats and values, and no asserted consumption. Existing activation handling records item identity/provenance; it does not reset every stat or invent prior drops.
- `<actor>扭曲了时空！`: `trick_room_change/start`, using the existing room representation.
- `<...进化石[XY]>和<...>起了反应！`: observation with `completed_transformation=False`. Existing `超级进化成了` remains the separate completion grammar.
- Exact `<actor>的<ability/item>` suffix recognition now correctly handles the initial `对手的` prefix. Unknown items, negated messages, and ability-menu fragments are negative controls.

Existing faint/send-out/stat-direction/status/weather/terrain/completed-transformation grammar is retained and regression tested. This milestone adds no mechanical rules. Every new construction has positive and negative tests. White Herb's textual restoration is usable partial evidence, not a mechanically computed stage transition.

## Move resolution and bounded OCR recovery

`recognition/move_resolution.py` uses the project's pinned `KnowledgeBase` Chinese move dictionary, snapshot `27b5fac46d4b8d5805476f4fd1d491efab1c8ae49e2b15e63cae8dfd6a0f16c5`. No new remote dictionary, model, or moveset assumption was introduced. Whitespace and terminal punctuation normalize; unique exact matches resolve. No battle-specific correction aliases were added. Similarity produces candidate IDs only and never confirms a move.

For noncanonical primary OCR, two distinct preprocessing configurations must agree on an exact canonical move with confidence >=0.90 and carry source hashes/configuration IDs. Contradictory high-confidence canonical alternatives prevent confirmation. Prefix fusion admits only alternatives whose frame hash occurs in the event's evidence. The original OCR, confidence, raw alternative readings, dictionary snapshot, method and candidates remain available. This is an engineering admission threshold, not calibrated probability. Multiple preprocessing runs of one image are correlated, not independent frame observations.

Manual review established evaluation labels only; production parsing does not read the reviewed fixture. Neither battle timestamps nor expected move names are parser inputs. The recovery runner explicitly selects four diagnostic examples; its shared line crop uses ROI rows 32–62 and the first 260 pixels, evaluated as native BGR, doubled cubic BGR, and grayscale BGR. It never opens a video. This fixed layout is deliberately limited; it is not a general new OCR schedule or arbitrary-layout recognizer.
