# M3.3 current in-game Ranked cache — pilot validation

The revised M3.3 direction uses [published team designs](M3.3-published-team-validation.md) as the central dataset. This completed Ranked aggregate pilot remains a separate reference population; its original results below are preserved.

Date: 2026-10-20 (Asia/Shanghai). **The nine-Pokémon current Ranked Doubles application-cache pilot is ready for review.** The main SQLite database contains only Champions Battle Data, labeled `third_party_claimed_ingame_ranked`. It contains no Showdown, tournament or MunchStats statistics. Source capture provenance and exact sample sizes are not independently established.

## Implemented scope

The new `metagame/` package provides current-API acquisition, original-byte hashing/retention, checkpointed error recovery, schema-versioned SQLite storage, exact shared-KnowledgeBase name/form resolution, typed distributions, offline table/JSON queries, completeness reporting and guarded statistical utilities. `pyproject.toml` registers its command and optional HTTP dependency. [Usage, cache policy and methodology](../docs/metagame-current-cache.md) document the public interface and statistical limits; the [source audit](M3.3-source-audit.md) covers all requested candidates and the final source choice.

Cache: `.cache/metagame/current-ranked/statistics.sqlite3`, schema version 1. Original API bytes, HTTP receipts and run manifests stay under the ignored application-cache root. No raw data dump, cache database or generated JSON is proposed for Git tracking.

The retained format source is `Current`, not an invented season/regulation identifier. The API index reports generation `2026-10-19T07:41:40.387Z`, data version `20261019074140387`, and **262 entries with current Doubles paths**. That is source-index coverage, not certified regulation legality. The pilot collected **9/262** such entries; the remaining 253 were not acquired. Wider collection and historical acquisition were not run.

## Cache and runtime validation

- Initial pilot: **10 GETs** (one index plus nine current battle endpoints), **18.355 seconds**, sequential with a two-second request interval. All nine species completed; no ingestion errors.
- Repeat pilot: **zero HTTP requests**, ten fresh-response cache hits, **0.086 seconds** measured ingestion body. Compatible bytes were reused; no video, OCR, models or battle replay ran.
- Forced scoped revalidation: index plus Pelipper/Archaludon, three GETs, **5.511 seconds**. The upstream returned HTTP **200**, not 304; exact body hashes stayed reusable. Conditional headers/304 behavior are covered by offline transport tests, not claimed as a live upstream 304 success.
- Measured SQLite footprint: **1,691,648 bytes**; ten unique raw current responses: **5,838,475 bytes**. The application-cache directory also contains small receipts/manifests and local query/coverage exports; these numbers are a pilot measurement, not a full-population storage estimate.
- Default refresh **24 hours**, retention **seven days**, maximum **two** retained response/parser versions per URL; these are configurable. Managed retention runs after successful refresh or explicit `prune`. No historical-season query or permanent mirror is implemented. All live-pilot pruning receipts report zero removed snapshots/raw files; unrelated historical/audit/battle caches were preserved.
- Snapshot writes and per-species database projections are durable/transactional; errors retain prior successful species. Repeating the command resumes from the compatible HTTP cache. Source-schema drift, checksum mismatch, duplicate ingestion, single-writer locking, timeout/backoff/rate limits and owned-cache retention are tested offline.

Refresh/resume commands:

```sh
.venv/bin/python -m metagame refresh
# Retry/revalidate only selected species when necessary:
.venv/bin/python -m metagame refresh --species Pelipper Archaludon --force
# Offline retention of this application cache only:
.venv/bin/python -m metagame prune --retention-days 7 --max-versions 2
```

The pilot/cache is reviewable; full-population collection and broader statistical acceptance remain incomplete.
