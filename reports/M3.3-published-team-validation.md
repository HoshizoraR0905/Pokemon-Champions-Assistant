2026-10-20. The revised M3.3 pilot is ready for review: a versioned local published-design database, two independent deduplication levels, explicit estimators, provenance/missingness reports and offline queries. The previous Ranked aggregate cache remains a separate unchanged reference.

These are observed counts from [PokeDaily's six retained public team sheets](https://pokedaily.net/champions/rentals/), using the **community / M-C / Unknown-format** cohort. Each distinct design has weight one. No values come from Ranked marginal percentages, artificial teams or repeated publications.

Every retained Pelipper design in this small community sample includes Archaludon. Consequently the conditioned and unconditioned frequencies above coincide; this is not evidence that Archaludon causes those build choices. There is no observed comparison group without Archaludon. No statistically reliable Ranked conclusion or confidence interval follows from these three curated designs.

## Query and reproduction

```sh
.venv/bin/python -m metagame.published query Pelipper \
  --population community_published --regulation M-C --format Unknown \
  --unit unique_composition --teammate Archaludon --output json
.venv/bin/python -m metagame.published query 大嘴鸥 \
  --population community_published --regulation M-C --format Unknown \
  --unit unique_build --teammate 铝钢桥龙
.venv/bin/python -m metagame.published query Pelipper \
  --population community_published --regulation M-C --format Unknown \
  --without-teammate Archaludon --output json
.venv/bin/python -m metagame.published query Pelipper \
  --population community_published --regulation M-C --format Unknown \
  --given-move Tailwind --move-pair Tailwind Protect --output json
```

[Implementation, schemas, cache/resume commands, source conditions and statistical methodology](../docs/published-team-designs.md) describe the full interface. Population/regulation are explicit; the default format is Doubles, so Unknown-format data requires an explicit selector. The standalone `champions-published-teams` entry point is registered; the module form works in the existing environment without reinstalling the project.

Database: `.cache/metagame/published-teams/teams.sqlite3`, schema **2**, fingerprint profile `published-team-identity-v1`. Final current-scope coverage and worked-example JSON live in `.cache/metagame/published-teams/review-v2/`. Earlier diagnostic exports predate the format correction and are retained as superseded diagnostics; they are not the accepted current-scope results. Canonical identities include version tags; complete builds and their composition children remain distinct. An implementation change cannot silently overwrite an existing fingerprint definition or canonical extraction. Partial-record compatibility only produces unproven candidate links.

Measured retained original pages: **318,231 bytes**. SQLite after the pilot/correction ledger: **561,152 bytes**. Original page/rental validity was not rechecked through the game. Page parsing and local ingestion completed in under one second per source; exact run durations and completion/error records are in `runs/*.json`. No video processing, OCR, battle replay or acquisition was run.
