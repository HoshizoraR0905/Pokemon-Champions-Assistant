## Measure and soft evidence

For a context population Ω of n eligible occurrences, P({ω}) = 1/n, including repeated identical builds. Let M_t contain only distinct executed opponent moves revealed by time t. Frequencies use **the same full retained context population**, before battle-specific conditioning:

- Raw p_m = k_m/n, where k_m counts occurrences containing m.
- Scoring frequency p̂_m = (k_m+a)/(n+a+b), with configurable a=b=0.5 by default.
- Q_t({ω}) = Z_t⁻¹ · 1_Ht(ω) · P({ω}) · ∏[m∈M_t∩template(ω)] p̂_m^(−α).
- Display core mass Q_t(C) = Σ[ω:core(ω)=C] Q_t({ω}).

[The scorer](../battle_evidence/empirical_measure.py) uses log weights and stable normalization. Smoothing is a finite-sample scoring regularizer, not an invented probability of an opponent selecting a move. An unseen move has a finite frequency and no matching template to reward; it never hard-excludes a core. Repeated execution of one move does not multiply its reward again. Unknown learnability stays unverified; soft ranking cannot bypass confirmed legality or numerical evidence. Numerical damage, stage/item evidence and Speed support remain hard constraints. Exhaustion stays explicit and does not erase Full Reference support. Unresolved mechanics receive a separate provisional/evaluated normalization.

The old Hatterene empirical catalog became empty because published templates lacked Psyshock and were treated as equipped moveset restrictions. Removing that restriction retains all 13 occurrences / 7 cores before the first HP result. The first actual damage equality then removes 12 occurrences, leaving one original complete joint core (Babiri Berry, Magic Bounce, Quiet, Sp. Atk 206, Speed 44); it survives both later hits. Its displayed 100% is conditional sample mass, not certainty about the opponent. Its source template need not contain all four battle-revealed moves.
